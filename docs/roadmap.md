# Дорожня карта

Кожен рядок — тікет зі спекою в `docs/specs/` і issue на GitHub. Номер тікета і номер issue не збігаються, бо issues і PR на GitHub мають спільну нумерацію; номер issue записується в колонку «Issue», коли issue створено.

Потоки: **A** — каркас і ядро, **B** — публікація, **C** — перенесення, **D** — експлуатація. Усередині потоку тікети йдуть по черзі; різні потоки можна вести паралельно, якщо блокери закриті.
