# Знахідки

Те, що легко забути або вгадати неправильно: пастки бібліотек, неочевидні рішення і їх причини. Кожна знахідка — окремий пункт з датою і номером тікета.

## Telegram

- 2026-10-09 (до #1). `copyMessage` не замінює текст текстового повідомлення; якщо правила змінили пост — відправляти заново. Деталі в [platform-notes.md](platform-notes.md#copymessage).

## Facebook

- 2026-10-09 (до #1). Публікація в групи через Graph API неможлива з квітня 2024; на запити про групи відповідь одна — лише сторінки.
