# #11 — Джерело-бот і маршрути

Потік C · Блокери: #7, #10

## Мета
Нові пости каналу, де бот адміністратор, автоматично переносяться в обрані напрямки з правилами.

## Що зробити
- Реєстрація джерела: у сценарії #4 до кнопок «Так» / «Ні» додається «Це джерело» → `Source(kind=BOT_CHANNEL)`.
- Меню «Маршрути»: створити маршрут (джерело → напрямок), увімкнути/вимкнути, керувати правилами (додати, змінити порядок, видалити, перевірити на тестовому тексті).
- Обробник `channel_post` → `AlbumBuffer` → `fromBotMessage` → для кожного маршруту `applyRules` → `PublicationService.createRelay(...)` з `sourceKey`.
- Повторне оновлення з тим самим `sourceKey` ловиться унікальним обмеженням і пропускається без помилки в лозі.
- Медіа відправляється за тим самим `file_id`; якщо правила не змінили пост — `copyMessage` / `copyMessages`.

## Критерії приймання
Пост у тестовому каналі-джерелі за кілька секунд з'являється в цільовому каналі без «Переслано з», із заміненими контактами.

## Тести
Інтеграційний: два однакові оновлення `channel_post` дають один `Post`.
