# #4 — Реєстрація Telegram-напрямків

Потік B · Блокери: #2, #3

## Мета
Адмін додає бота в групу чи канал, і той стає напрямком публікації без ручного введення chat_id.

## Що зробити
- Обробник `my_chat_member`: коли новий статус бота — `administrator` (для каналу з `can_post_messages`) або `member` у групі, бот пише кожному адміну: «Мене додали в „<назва>“. Публікувати туди?» з кнопками «Так» / «Ні».
- «Так» — upsert `Destination(kind=TELEGRAM_CHAT, externalId=chat.id, title)`.
- Статус `left` / `kicked` або втрата права публікації — `enabled=false`, `disabledReason`, повідомлення адміну.
- Меню «Напрямки»: список з позначкою увімкнено/вимкнено, перемикання кнопкою, видалення з підтвердженням.

## Критерії приймання
- Додати бота адміністратором у тестовий канал → прийшла пропозиція → після «Так» канал у списку.
- Забрати в бота право публікації → напрямок вимкнено, адмін отримав повідомлення.

## Нюанси
Супергрупа після міграції з групи отримує новий id (`migrate_to_chat_id`) — оновити `externalId` наявного напрямку, а не створювати новий.

## Тести
Юніт: перехід статусів `my_chat_member` → дія (запропонувати / вимкнути / нічого).
