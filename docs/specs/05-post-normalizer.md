# #5 — Модель поста і нормалізатор grammY

Потік A · Блокери: #1

## Мета
Один тип `PostDraft` (див. [architecture.md](../architecture.md#внутрішня-модель-поста)), у який перетворюється будь-яке підтримуване повідомлення Telegram.

## Що зробити
- Типи `PostDraft`, `PostMedia` у `src/posts/`.
- `fromBotMessage(message)`: текст з `entities`; фото (найбільший розмір з `photo[]`), відео, документ, анімація з `caption` і `caption_entities`.
- Непідтримувані типи (опитування, стікер, голосове, кружечок, локація) — помилка `UnsupportedPostError` з назвою типу; бот відповідає адміну, що такий пост не публікується.
- Серіалізація `PostDraft` у JSON для `Post.payload` (без `buffer`).

## Критерії приймання
Кожен підтримуваний тип дає коректний `PostDraft`; непідтримуваний — зрозуміле повідомлення адміну.

## Тести
Юніт на фікстурах реальних об'єктів `Message` (зберегти в `test/fixtures/`): текст із форматуванням і емодзі, фото з підписом, відео, документ, стікер.
