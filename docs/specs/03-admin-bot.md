# #3 — Адмін-бот: доступ і головне меню

Потік A · Блокери: #1

## Мета
Бот, з яким працює лише власник: решта користувачів не отримує відповіді.

## Що зробити
- `AdminBotModule` на grammY; запуск через `@grammyjs/runner` після старту Nest, зупинка в `onApplicationShutdown`.
- Middleware доступу: оновлення від користувача поза `ADMIN_IDS` ігнорується, у лог — лише id.
- `/start` — головне меню (inline-клавіатура): «Новий пост», «Напрямки», «Маршрути», «Журнал». Кнопки поки відповідають «Скоро».
- Встановити список команд через `setMyCommands`.

## Критерії приймання
- Адмін бачить меню на `/start`; інший акаунт не отримує нічого.
- Зупинка застосунку (Ctrl+C) коректно зупиняє long polling без помилок у логах.

## Тести
Юніт-тест middleware доступу з фейковим контекстом grammY.
